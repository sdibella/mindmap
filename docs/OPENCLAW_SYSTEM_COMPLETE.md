### 2. Three Unified Scripts

#### **Nightly: vault-intelligence-engine.py**
**Purpose:** Autonomous categorization and backlinking
**Schedule:** 2:00 AM daily
**Duration:** 2-3 minutes
**What it does:**
- Scans all markdown files in vault
- Applies protocol rules to categorize each file
- Calculates similarity scores between all files
- Generates backlink recommendations
- Outputs: `vault-metadata.json` (reference for weekly/monthly)

#### **Weekly: weekly-review.py**
**Purpose:** Surface anomalies and opportunities
**Schedule:** Monday 8:00 AM
**Duration:** 1-2 minutes
**What it does:**
- Reads metadata from nightly run
- Identifies low-confidence categorizations
- Finds edge cases and emerging patterns
- Outputs: `WEEKLY_REVIEW.md` (for your review)

#### **Monthly: monthly-synthesis.py**
**Purpose:** Deep learning and protocol evolution
**Schedule:** 1st of month, 9:00 AM
**Duration:** 2-3 minutes
**What it does:**
- Analyzes month of categorization data
- Identifies hub atoms and isolated content
- Detects emerging patterns
- Proposes protocol updates
- Outputs: `MONTHLY_SYNTHESIS.md` (for your approval)


### Metadata not updating
```bash
# Verify nightly ran
ls -la vault-metadata.json
```
